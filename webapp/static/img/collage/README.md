# Коллажные ассеты бренда

Лендинг рисует эти картинки **только если файл реально лежит здесь**
(`has_static()` в `webapp/templating.py`) — пока файла нет, вместо коллажа
работает векторный запасной вариант, битых `<img>` не появляется.

| Имя файла | Размер | Что это | Где используется |
|---|---|---|---|
| `crt-vpn.webp` | 950×924 | ЭЛТ-монитор с надписью VPN | Главная иллюстрация hero. Без неё рисуется SVG-глобус |
| `flip-phone-vpn.webp` | 420×733 | Телефон-раскладушка с VPN на экране | Акцент секции «Зачем нужен», только от 1280px |
| `tape-blue.webp` | 420×261 | Полоска синего скотча | Крепит монитор в hero и карточку финального CTA |
| `paper-torn.webp` | 640×306 | Обрывок бумаги | Текстура в финальном CTA |

## Требования к замене

- **WebP с альфа-каналом.** PNG для этих фактур весит в 6–7 раз больше при той же
  картинке (2.4 МБ против 390 КБ на все четыре), а `crt-vpn` — LCP-элемент главной.
- **Обрезать по видимому контуру.** Генераторы оставляют вокруг объекта гало с
  альфой 1–4: глазу оно невидимо, но раздувает холст — у `paper-torn` исходник был
  прозрачным на 60% площади. Режь по `alpha >= 8`.
- **Ширину не увеличивать.** Размеры выше подобраны под реальный размер отрисовки
  с запасом на 2× экраны; апскейл только утяжелит файл.
- **Имена и пропорции.** Имена захардкожены в `templates/index.html`, там же в
  `width`/`height` записаны размеры — их надо править вместе с картинкой, иначе
  браузер зарезервирует место не по той пропорции и вёрстка дёрнется при загрузке.

Подготовка исходника (обрезка + ресайз + сжатие) — `tools/make_collage.py`.
