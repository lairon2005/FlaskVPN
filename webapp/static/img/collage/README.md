# Коллажные ассеты бренда

Лендинг рисует эти картинки **только если файл реально лежит здесь**
(`has_static()` в `webapp/templating.py`) — пока файла нет, вместо коллажа
работает векторный запасной вариант, битых `<img>` не появляется.

| Имя файла | Что это | Где используется |
|---|---|---|
| `crt-vpn.png` | ЭЛТ-монитор с надписью VPN, фон прозрачный | Главная иллюстрация hero. Без неё рисуется SVG-глобус |
| `flip-phone-vpn.png` | Телефон-раскладушка с VPN на экране | Акцент секции «Зачем нужен», только от 1280px |
| `tape-blue.png` | Полоска синего скотча | Крепит монитор в hero и карточку финального CTA |
| `paper-torn.png` | Обрывок бумаги | Текстура в финальном CTA |

Требования: PNG с альфа-каналом, длинная сторона 1200–1600px.
Имена менять нельзя — они захардкожены в `templates/index.html`.
